Política de privacidad

Finanzas Historias · Vigente desde el 29 de septiembre de 2026

Esta política describe cómo la aplicación Finanzas Historias (en adelante, "la aplicación") maneja los datos. La aplicación es una herramienta de automatización de uso personal, operada por su desarrollador únicamente sobre su propia cuenta de YouTube.

Datos a los que accede la aplicación

La aplicación solicita autorización a Google/YouTube mediante OAuth 2.0 con los siguientes permisos, con el único fin de publicar videos en el canal del propio usuario:

  • youtube.upload: subir videos al canal del usuario.
  • youtube.force-ssl: gestionar los videos subidos (miniatura y subtítulos).

La aplicación no accede a datos personales de terceros ni recopila información de visitantes de este sitio.

Almacenamiento y uso de los datos

  • El token de autorización de OAuth se guarda de forma local en el equipo del usuario y se utiliza solo para autenticar las llamadas a la API de YouTube.
  • La aplicación no transmite ni comparte ese token ni ningún dato con terceros.
  • No se venden datos. No se usan datos para publicidad.

Uso limitado (Google API Services User Data Policy)

El uso que la aplicación hace de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado (Limited Use).

Revocación

El usuario puede revocar el acceso en cualquier momento desde la configuración de su cuenta de Google. Al revocarlo, la aplicación deja de poder subir videos.
